# Academic Website — Nguyen Bao Trung

Source for the bilingual academic website and research portfolio at [trungnb.github.io](https://trungnb.github.io/).

The site focuses on **CBCT research, 3D dental imaging, quantitative analysis, and exploratory AI/software projects**.

## Structure

- `_pages/` — home, publications/projects indexes, and CV
- `_publications/` — peer-reviewed publications
- `_portfolio/` — selected research and software projects
- `files/` — supporting award evidence
- `images/` — profile image and site icons

English and Vietnamese content use matching `translation_key` values. The `main` branch is published with GitHub Pages.
